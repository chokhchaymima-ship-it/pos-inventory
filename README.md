# งานที่ 2: ระบบบริหารจัดการคำสั่งซื้อและคลังสินค้าหน้าร้าน
### Point of Sale and Inventory Management System

ระบบจำลองการขายหน้าร้าน (POS) และตัดสต็อกสินค้าเรียลไทม์ พัฒนาด้วย **React** และ **Material UI (MUI)** ตามข้อกำหนดทั้งหมด

---

## 🌟 ฟังก์ชันการทำงานที่พัฒนาตรงตามข้อกำหนด

### 1. การจัดการรายการสินค้าและสต็อก (Inventory Control)
- ✅ **แสดงรายการสินค้าพร้อมจำนวนคงเหลือ**: แสดงข้อมูลสินค้า ราคา รูปภาพ และสต็อกคงเหลือ
- ✅ **เตือนสินค้าใกล้หมด**: หากสินค้าคงเหลือน้อยกว่า 5 ชิ้น (`stock < 5`) แสดงสถานะและ Chip เตือน `⚠️ สินค้าใกล้หมด` พร้อมสีกรอบและหลอดสถานะเด่นชัด
- ✅ **ตัดสต็อกแบบเรียลไทม์**: เมื่อกดยืนยันชำระเงิน สต็อกจะถูกหักออกทันทีตามจำนวนที่สั่งซื้อ
- ✅ **LinearProgress**: แสดงแท่งสัดส่วนสต็อกคงเหลือเทียบกับสต็อกเริ่มต้น

### 2. การคำนวณคำสั่งซื้อและส่วนลด (Transaction Calculation)
- ✅ **คำนวณราคารวม**: คำนวณ Subtotal อัตโนมัติตามสินค้าและจำนวนในตะกร้า
- ✅ **ภาษีมูลค่าเพิ่ม (VAT 7%)**: คำนวณ VAT 7% ของยอดสินค้าหลังหักส่วนลด
- ✅ **การใช้โค้ดส่วนลด (Discount Code)**: รองรับการกรอกโค้ด เช่น:
  - `DISCOUNT10` (ลด 10%)
  - `DISCOUNT20` (ลด 20%)
  - `SAVE50` (ลด 50 บาท)
- ✅ **คำนวณเงินทอนและใบเสร็จ**:
  - ช่องกรอกจำนวนเงินที่รับ (พร้อมปุ่มลัดเลือกจำนวนเงิน ฿100, ฿500, ฿1000)
  - คำนวณเงินทอนอัตโนมัติ
  - แสดง Popup **ใบเสร็จรับเงินย่อ** ที่มีเลขที่ใบเสร็จ วันที่ รายการสินค้า และปุ่มพิมพ์ใบเสร็จ

### 3. การควบคุมสถานะการขาย (Status Control)
- ✅ **Switch**: สวิตช์สำหรับเปิด-ปิดการจำหน่ายสินค้าแต่ละรายการได้ทันที หากปิดจะไม่สามารถกดเพิ่มลงตะกร้าได้

---

## 🎨 รายการ MUI Components ที่นำมาใช้ตรงตามข้อกำหนด 100%

| หมวดหมู่ | MUI Components ที่ใช้งาน | หน้าที่ในระบบ |
| :--- | :--- | :--- |
| **Navigation & Header** | `AppBar`, `Toolbar`, `Badge` | เมนูด้านบนและ Badge ตัวเลขแสดงจำนวนสินค้าในตะกร้า |
| **Data Presentation** | `Card`, `CardMedia`, `CardContent`, `CardActions` | การแสดงการ์ดรายการสินค้า รูปภาพ รายละเอียด และปุ่มสั่งซื้อ |
| | `Table`, `TableHead`, `TableRow`, `TableCell` | ตารางแสดงรายการสินค้าในตะกร้า และตารางในใบเสร็จรับเงินย่อ |
| **Inputs & Controls** | `Switch` | เปิด/ปิดสถานะการขายของสินค้าแต่ละรายการ |
| | `TextField` | ช่องกรอกโค้ดส่วนลด และช่องกรอกจำนวนเงินที่รับ |
| | `IconButton` | ปุ่มเพิ่ม (+), ลด (-), และลบ (ถังขยะ) สินค้าในตะกร้า |
| **Feedback** | `Snackbar` | การแจ้งเตือน Toast เมื่อเพิ่มสินค้าลงตะกร้า หรือเมื่อเปิด/ปิดสถานะขาย |
| | `LinearProgress` | แถบแสดงสัดส่วนสต็อกสินค้าคงเหลือเทียบกับสต็อกเริ่มต้น |

## 🚀 วิธีเปิดใช้งาน

### วิธีที่ 1: เปิดใช้งานได้ทันที (Standalone - Zero Setup)
สามารถเปิดไฟล์ `index.html` บนเบราว์เซอร์ใดก็ได้ (เช่น Chrome, Edge) ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม ระบบจะโหลด React และ Material UI ผ่าน CDN พร้อมใช้งานครบทุกฟังก์ชัน

### วิธีที่ 2: รันใน GitHub Codespaces / GitHub IDE / VS Code
หากเปิดใน GitHub Codespaces หรือเครื่องที่มี Node.js:
```bash
# 1. ติดตั้ง Dependencies
npm install

# 2. เริ่มต้นรันโปรเจกต์
npm run dev
```
จากนั้นเปิด URL ที่แสดงบนหน้าต่าง Terminal (เช่น `http://localhost:5173`)
